🚧 目前不支持 / 待完善的语法

以下写法目前不会按预期渲染，留作日后改进（届时删掉对应小节即可）：

1. [TOC] 目录占位符

[TOC]

2. 代码行高亮语法 ```cpp{1,3}

3. Mermaid 代码围栏（请使用 {% mermaid %} 标签代替）

启用行号的代码块会破坏 Mermaid 源码，因此围栏写法渲染结果不可控；请统一使用上文 {% mermaid %} 标签。

4. 未注册的标签插件（如 {% youtube %}）

Fluid 内置标签：note / button / checkbox / fold / label / mermaid / group-image（均可正常使用）。但使用未注册的标签（例如 youtube 视频嵌入）会导致构建直接报错中止，因此这类写法应当避免。
