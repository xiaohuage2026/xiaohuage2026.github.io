管理员登录

本页面通过 GitHub API 直接读取 / 修改仓库中的文章源码（blog/source/_posts/）。只有对仓库有写权限的 GitHub 账户（管理员 / 协作者）才能保存、新建或删除文章——其他访客没有令牌，无法做任何修改。

获取方式（推荐 Fine-grained Token）：
GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token：
① Resource owner 选择 xiaohuage2026；② Repository access 仅勾选 xiaohuage2026.github.io；
③ Permissions → Repository permissions → Contents: Read and write（Metadata 只读会自动附带）。
令牌仅保存在当前标签页会话（sessionStorage），关闭标签页即销毁；验证通过前不会加载任何编辑功能。
