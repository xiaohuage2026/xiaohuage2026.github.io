🔒 管理员解锁

输入管理员密码，解锁本浏览器中加密保存的 GitHub 令牌。解锁后会自动向 GitHub 校验仓库写权限——只有管理员（对仓库有写权限的账户）才能进入。

🛠️ 首次设置管理员密码

本页面通过 GitHub API 直接读写仓库文章源码（blog/source/_posts/）。先粘贴你的 GitHub Fine-grained Token（仅本仓库、Contents: Read and write），并设置一个管理员密码——令牌会用你的密码加密后仅保存在本浏览器中。

安全说明
① 密码不会被上传到任何地方，仅用于在本地用 AES-256-GCM（PBKDF2 派生，25 万次迭代）加密解密令牌；密码至少 12 位且含字母和数字；
② 加密后的令牌保存在本浏览器 localStorage，换设备 / 换浏览器需重新设置；
③ 即使令牌被离线拿到，没有密码也无法解密；而 GitHub 服务端始终校验写权限；
④ 密码只保护「存储在本浏览器的令牌」，它不是多用户账号体系，请勿与他人共享。

  • 本站使用 KaTeX 渲染：未知命令会原样显示为红色源码，请检查拼写。
